### Матриця нефункціональних вимог (NFRs)

| Категорія | Метрика | Цільове значення |
|---|---|---|
| **Продуктивність** | Latency Ingestion API (p95) | ≤ 200 мс при 500 RPS |
| **Продуктивність** | Затримка «запис → read-модель» (p95) | ≤ 2 с |
| **Масштабованість** | Kafka consumer lag | < 1000 повідомлень |
| **Надійність** | Доступність (SLO) / Доставка | ≥ 99,9% / at-least-once (ідемпотентні споживачі) |
| **Надійність** | RPO / RTO | ≤ 5 хв / ≤ 30 хв |
| **Безпека** | Автентифікація / Шифрування | OAuth 2.0 (OIDC), AES-256-GCM (для PHI) |
